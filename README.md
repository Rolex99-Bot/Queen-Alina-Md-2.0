## 🚀 Quick Start

### Prerequisites
- Node.js >= 18.0.0
- Git

### Installation

```bash
# Clone repository
git clone https://github.com/abdulazeez/queen-alina-md-2.0.git

# Enter directory
cd queen-alina-md-2.0

# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Edit .env with your details

# Start the bot
npm start
```

### Pair Code Login
1. Run `npm start`
2. Enter your WhatsApp number with country code (e.g., `94775153939`)
3. Enter the pair code in WhatsApp: **Settings → Linked Devices → Link with phone number**
4. Done! Bot is connected!
